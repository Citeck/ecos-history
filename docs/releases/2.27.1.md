# History 2.27.1

COREDEV-630 delivers the Records attribute processor fix through Webapp Commons
3.34.7, which pins Records 3.79.2. The previous History parent was 3.33.0.

When an association display name contains JSON text, a fallback expression such
as `?disp!_type?disp!?localId` now preserves the string instead of converting it
to a JSON object. This prevents `MismatchedInputException` while reading
`record-created` events for process definition revisions.

The change does not repair previously failed events or change the calculation
of `dispML` for `proc-def-repo`. Deployment and verification of a newly generated
event on enterprise.ecos24 are separate from publishing this release.

Release validation uses `mvn clean verify` with JDK 25.
